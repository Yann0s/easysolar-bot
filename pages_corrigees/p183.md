Annexe C : raccordements sur la carte électronique du convertisseur (MultiPlus Compact)
- C : port de communication (deux prises RJ45) : câble UTP, utilisé pour VE-Configure et pour un tableau de commande Multi Control.
- Indicateur du relais programmable : une LED (marquée ALARM) s'allume quand le relais est activé.
- D : sonde de température (bornier 2 points) : 1 = fil rouge, sonde + ; 2 = fil noir, sonde −.
- H : interrupteur à distance (bornier 3 points) : 1 = chargeur uniquement (charger only) ; 2 = borne du milieu (terre !) ; 3 = on. Un interrupteur 3 voies se raccorde à cette borne H.
- E : contact d'alarme (relais, bornier 3 points) : 1 = NO (normalement ouvert) ; 2 = COM (commun) ; 3 = NC (normalement fermé).
